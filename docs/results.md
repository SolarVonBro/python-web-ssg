## Данные и модель

Набор `data/measurements.csv`: две группы по 60 наблюдений.
Для каждой группы подбирается линейная модель $y = a x + b$ методом
наименьших квадратов, качество оценивается через

\[
R^2 = 1 - \frac{\sum_i (y_i - \hat y_i)^2}{\sum_i (y_i - \bar y)^2}.
\]
